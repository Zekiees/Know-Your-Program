Lesson 1: Introduction to CSS

CSS (Cascading Style Sheets) styles and layouts HTML elements, controlling colors, fonts, spacing, and more.

body {
  background-color: #121212;
  color: white;
  font-family: Arial, sans-serif;
}

Lesson 2: CSS Syntax

CSS uses selectors and declarations to define how elements look.

selector {
  property: value;
}

h1 {
  color: blue;
  font-size: 24px;
}

Lesson 3: Selectors

Selectors target HTML elements — use element, class, or ID selectors.

p { color: gray; }
.button { background: blue; }
#main-title { font-weight: bold; }

Lesson 4: Colors & Backgrounds

Use colors and gradients to style your site visually.

body {
  background-color: #0d1117;
  color: #e7ecff;
}

header {
  background-image: linear-gradient(90deg, #264de4, #2965f1);
}

Lesson 5: Text Styling

Change font, alignment, spacing, and effects with CSS.

h1 {
  font-family: "Segoe UI", sans-serif;
  text-align: center;
  text-shadow: 0 0 8px #00c8ff;
}

p {
  line-height: 1.6;
  color: #ccc;
}

Lesson 6: Box Model

Every HTML element is a box made of content, padding, border, and margin.

div {
  width: 200px;
  padding: 10px;
  border: 2px solid #2965f1;
  margin: 15px;
  background-color: #111827;
}

Lesson 7: Positioning

Position elements anywhere using static, relative, absolute, fixed, or sticky.

.box {
  position: absolute;
  top: 50px;
  left: 100px;
}

Lesson 8: Flexbox

Flexbox makes aligning and spacing items in a container easy.

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 1rem;
}

Lesson 9: Grid

CSS Grid is a 2D system for complex layouts.

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}

Lesson 10: Pseudo-classes

Define element states like hover or focus.

a:hover {
  color: #00c8ff;
  text-decoration: underline;
}

Lesson 11: Transitions

Add smooth visual effects when properties change.

button {
  background: #2965f1;
  transition: background 0.3s ease;
}

button:hover {
  background: #1b3fa2;
}

Lesson 12: Animations

Make elements move or fade using keyframes.

@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

.box {
  animation: fadeIn 1s ease-in-out;
}

Lesson 13: Variables

CSS variables store reusable color, size, or font values.

:root {
  --main-color: #2965f1;
  --text-light: #e7ecff;
}

button {
  background: var(--main-color);
  color: var(--text-light);
}

Lesson 14: Media Queries

Make designs responsive using conditional CSS rules.

@media (max-width: 600px) {
  body {
    font-size: 14px;
    background: #0d1117;
  }
}

Lesson 15: Best Practices

Keep your CSS readable and well-organized for maintainability.

/* Use clear class names */
.navbar {}
.footer {}

/* Separate layout and theme */
.layout { display: flex; }
.theme-dark { background: #0d1117; }

Lesson 16: Pseudo-elements

Pseudo-elements style specific parts of elements, like the first line or before/after content.

p::first-line {
  font-weight: bold;
}

button::after {
  content: " →";
}

Lesson 17: Responsive Design

Responsive design ensures your site looks good on all screen sizes.

img {
  max-width: 100%;
  height: auto;
}

.container {
  padding: 1rem;
}

Lesson 18: CSS Frameworks

Frameworks like Bootstrap and Tailwind CSS speed up development with prebuilt styles and utilities.

/* Example (Tailwind) */
<button class="bg-blue-600 text-white px-4 py-2 rounded">Click Me</button>
