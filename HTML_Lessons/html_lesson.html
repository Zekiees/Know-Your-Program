Lesson 1: Introduction to HTML

HTML stands for HyperText Markup Language. It is the backbone of all web pages.

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello World!</h1>
  </body>
</html>

Lesson 2: Setup

Every HTML file starts with a <!DOCTYPE html> and the basic structure.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>Setup Example</title>
  </head>
  <body>
    <p>This is my first HTML setup.</p>
  </body>
</html>

Lesson 3: Structure

HTML uses elements like <header>, <main>, and <footer> to structure content.

<header>
  <h1>My Website</h1>
</header>

<main>
  <p>This is the main content.</p>
</main>

<footer>
  <p>© 2025 My Site</p>
</footer>

Lesson 4: Text

HTML supports headings, paragraphs, and text formatting.

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<p>This is a <strong>bold</strong> word.</p>
<p>This is an <em>italic</em> word.</p>

Lesson 5: Links & Images

Use <a> for links and <img> for images.

<a href="https://example.com">Visit Example</a>

<img src="https://picsum.photos/200" alt="Random Image">

Lesson 6: Lists

HTML has ordered (<ol>) and unordered (<ul>) lists.

<ul>
  <li>Apples</li>
  <li>Bananas</li>
</ul>

<ol>
  <li>First</li>
  <li>Second</li>
</ol>

Lesson 7: Tables

Tables display data in rows and columns.

<table border="1">
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Alice</td>
    <td>20</td>
  </tr>
</table>

Lesson 8: Forms

Forms let users input data like text, emails, or passwords.

<form>
  <label>Name: <input type="text"></label><br>
  <label>Email: <input type="email"></label><br>
  <button type="submit">Submit</button>
</form>

Lesson 9: Semantic HTML

Semantic tags help describe meaning: <article>, <nav>, <aside>.

<nav>
  <a href="#">Home</a> |
  <a href="#">About</a>
</nav>

<article>
  <h2>Blog Post</h2>
  <p>This is a semantic example.</p>
</article>

Lesson 10: Media

You can add videos and audio to a webpage.

<video width="300" controls>
  <source src="video.mp4" type="video/mp4">
</video>

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
</audio>

Lesson 11: Iframes

An iframe embeds another webpage into your page.

<iframe src="https://example.com" width="400" height="200"></iframe>

Lesson 12: HTML APIs

Some HTML APIs include Canvas, Drag & Drop, and Geolocation.

<canvas id="myCanvas" width="200" height="100"></canvas>

<script>
  const c = document.getElementById("myCanvas");
  const ctx = c.getContext("2d");
  ctx.fillStyle = "red";
  ctx.fillRect(20, 20, 150, 50);
</script>

Lesson 13: CSS Intro

CSS is used to style HTML content.

<style>
  body { background: lightblue; }
  h1 { color: darkblue; }
</style>

<h1>Styled Heading</h1>

Lesson 14: Responsive

Use media queries to make websites mobile-friendly.

<style>
  body { font-size: 16px; }
  @media (max-width: 600px) {
    body { font-size: 12px; }
  }
</style>

Lesson 15: Projects

Build small projects to practice what you learned.

<ul>

  <li>Project 2</li>
</ul>
