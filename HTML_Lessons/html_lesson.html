What is HTML?

HTML is the foundation of all webpages. It structures content like headings, paragraphs, links, and images for browsers to display.

Setup & File Structure

Every HTML document begins with <!DOCTYPE html>. It contains the <html>, <head>, and <body> tags.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My Page</title>
  </head>
  <body>
    <p>Hello World!</p>
  </body>
</html>

Tags & Attributes

HTML elements are represented by tags. Attributes provide extra info, like href for links or src for images.

<a href="https://example.com" target="_blank">Visit Example</a>
<img src="image.jpg" alt="Alt text">

Text & Headings

Use headings (<h1>–<h6>) for titles and <p> for paragraphs. Use <strong> for bold and <em> for italics.

<h1>Heading 1</h1>
<p>This is a paragraph with <strong>bold</strong> text.</p>

Links & Images

Links (<a>) navigate users, while images (<img>) display pictures. Always include alt text for accessibility.

<a href="https://example.com">Visit Example</a>
<img src="https://picsum.photos/200" alt="Random Image">

Lists

Unordered lists (<ul>) use bullets; ordered lists (<ol>) use numbers. List items are <li>.

<ul>
  <li>Apple</li>
  <li>Banana</li>
</ul>

<ol>
  <li>First</li>
  <li>Second</li>
</ol>

Tables

Tables organize data into rows (<tr>) and columns (<td>). Use <th> for headings.

<table border="1">
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Alice</td>
    <td>20</td>
  </tr>
</table>

Forms

Forms allow users to submit data like text, email, or passwords, with labels and buttons for input and submission.

<form>
  <label>Name: <input type="text"></label><br>
  <label>Email: <input type="email"></label><br>
  <button type="submit">Submit</button>
</form>

Audio & Video

Use <audio> and <video> to embed media. Controls let users play, pause, or adjust volume.

<audio controls>
  <source src="song.mp3" type="audio/mpeg">
</audio>

<video width="300" controls>
  <source src="video.mp4" type="video/mp4">
</video>

Iframes

An iframe embeds another webpage inside your page for content like maps, videos, or external websites.

<iframe src="https://example.com" width="300" height="200"></iframe>

Semantic HTML

Semantic tags provide meaning: <header> for headers, <nav> for navigation, <article> for independent sections, and <footer> for footers.

<header>Header</header>
<nav>Navigation</nav>
<main>Main Content</main>
<footer>Footer</footer>

Classes & IDs

Classes (class) apply styles to multiple elements. IDs (id) uniquely identify one element for CSS/JS.

<div id="unique" class="card highlight">Content</div>

Meta Tags

Meta tags store page info, such as character set, description, and keywords. Important for SEO and page metadata.

<meta charset="UTF-8">
<meta name="description" content="Learn HTML step by step">

Responsive Images

Responsive images adapt to screen sizes using <picture> or srcset for better mobile experience.

<picture>
  <source media="(max-width: 600px)" srcset="small.jpg">
  <img src="large.jpg" alt="Responsive image">
</picture>

HTML Entities

Entities represent special characters like &amp; (&), &lt; (<), or &gt; (>).

& < > " '

Data Attributes

Store extra info on elements for JavaScript without affecting content. Syntax: data-key="value".

<div data-user="Ezekiel">Hello</div>

SVG Graphics

SVG creates scalable vector graphics directly in HTML. Perfect for icons or illustrations that stay sharp at any size.

<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" stroke="green" fill="yellow" />
</svg>

Canvas (Advanced)

The <canvas> element allows drawing graphics via JavaScript for animations, charts, or games.

<canvas id="myCanvas" width="200" height="100"></canvas>
<script>
const c = document.getElementById("myCanvas");
const ctx = c.getContext("2d");
ctx.fillStyle = "red";
ctx.fillRect(20, 20, 150, 50);
</script>

Accessibility (ARIA)

ARIA roles help screen readers interpret content. Use roles and attributes for a more accessible site.

<button role="switch" aria-checked="false">Toggle</button>

SEO HTML

Proper headings, semantic tags, alt text, and meta tags improve search engine rankings.

Open Graph Tags

Open Graph tags control how your page appears on social media with title, description, and images.

<meta property="og:title" content="My Page">
<meta property="og:description" content="HTML Tutorial">
<meta property="og:image" content="image.jpg">
