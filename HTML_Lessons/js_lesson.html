Lesson 1: Introduction to JavaScript

JavaScript (JS) is a scripting language that makes web pages interactive and dynamic.

<script>
  alert("Welcome to JavaScript!");
</script>

Lesson 2: Syntax & Output

JS statements end with semicolons. Use console.log() to display output.

console.log("Hello, world!");
document.write("This is JavaScript output!");
alert("Pop-up example!");

Lesson 3: Variables

Variables store data values using var, let, or const.

let name = "Ezekiel";
const year = 2025;
var age = 20;

console.log(name, year, age);

Lesson 4: Data Types

JS supports strings, numbers, booleans, arrays, and objects.

let text = "Hello";      // String
let num = 100;           // Number
let isTrue = true;       // Boolean
let fruits = ["Apple", "Banana"]; // Array
let user = { name: "Ezekiel", age: 20 }; // Object

Lesson 5: Operators

Use operators to perform calculations or comparisons.

let sum = 10 + 5;     // Addition
let diff = 10 - 3;    // Subtraction
let isEqual = (5 == "5"); // true
let strictEqual = (5 === "5"); // false

Lesson 6: Conditional Statements

Use if, else if, and else to make decisions.

let score = 85;

if (score >= 90) {
  console.log("Excellent!");
} else if (score >= 75) {
  console.log("Good job!");
} else {
  console.log("Keep trying!");
}

Lesson 7: Loops

Loops repeat code multiple times.

for (let i = 1; i <= 5; i++) {
  console.log("Count: " + i);
}

let count = 0;
while (count < 3) {
  console.log("While loop " + count);
  count++;
}

Lesson 8: Functions

Functions are reusable blocks of code that perform specific tasks.

function greet(name) {
  return "Hello, " + name + "!";
}

console.log(greet("Ezekiel"));

Lesson 9: Arrays

Arrays store multiple values in one variable.

let colors = ["Red", "Green", "Blue"];

colors.push("Yellow");
console.log(colors[0]);  // Red
console.log(colors.length); // 4

Lesson 10: Objects

Objects store data as key-value pairs.

let person = {
  name: "Ezekiel",
  age: 20,
  greet: function() {
    console.log("Hi, I'm " + this.name);
  }
};

person.greet();

Lesson 11: DOM Manipulation

DOM lets you interact with HTML elements dynamically.

<h1 id="title">Hello</h1>
<script>
  document.getElementById("title").innerText = "Welcome to JS!";
</script>

Lesson 12: Events

Events respond to user actions like clicks or keypresses.

<button onclick="sayHello()">Click Me</button>

<script>
function sayHello() {
  alert("Hello there!");
}
</script>

Lesson 13: ES6 Features

Modern JavaScript includes arrow functions, template literals, and more.

// Arrow function
const greet = name => `Hello, ${name}!`;

// Template literal
let item = "Laptop";
console.log(`I bought a new ${item}.`);

Lesson 14: Debugging

Use the browser console to find and fix errors.

console.log("Debug message");
console.error("This is an error!");
console.warn("This is a warning!");

Lesson 15: Mini Projects

Build small projects like a counter or calculator to practice.

<button onclick="increase()">+</button>
<span id="count">0</span>
<button onclick="decrease()">-</button>

<script>
let count = 0;
function increase() {
  count++;
  document.getElementById("count").innerText = count;
}
function decrease() {
  count--;
  document.getElementById("count").innerText = count;
}
</script>
