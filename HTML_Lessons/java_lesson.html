What is Java?

Java is a high-level, object-oriented programming language designed to be platform-independent using the JVM.

Setup & Installation

To run Java programs, install the JDK and use an IDE like IntelliJ, Eclipse, or VS Code.

public class Main {
  public static void main(String[] args) {
    System.out.println("Hello World!");
  }
}

Java Syntax

Java programs use classes and methods. Execution starts from the main method.

class Example {
  public static void main(String[] args) {
    int x = 10;
    System.out.println(x);
  }
}

Variables & Data Types

Variables store data. Java has primitive and reference data types.

int age = 20;
double price = 99.99;
char grade = 'A';
boolean isJavaFun = true;

Operators

Operators perform operations like arithmetic, comparison, and logic.

int a = 10, b = 5;
System.out.println(a + b);
System.out.println(a > b);

Conditionals

Conditionals control program flow using if, else, and switch.

if (age >= 18) {
  System.out.println("Adult");
} else {
  System.out.println("Minor");
}

Loops

Loops repeat code execution using for, while, or do-while.

for (int i = 1; i <= 5; i++) {
  System.out.println(i);
}

Methods

Methods are reusable blocks of code that perform a specific task.

static int add(int a, int b) {
  return a + b;
}

Arrays

Arrays store multiple values of the same type.

int[] numbers = {1, 2, 3, 4};
System.out.println(numbers[0]);

Strings

Strings represent text and come with built-in methods.

String name = "Ezekiel";
System.out.println(name.length());

OOP Concepts

Java follows Object-Oriented Programming: encapsulation, inheritance, polymorphism, and abstraction.

Classes & Objects

Classes are blueprints; objects are instances of classes.

class Car {
  String model;
}

Car c = new Car();
c.model = "Toyota";

Inheritance

Inheritance allows a class to acquire properties of another class.

class Animal {
  void sound() {}
}

class Dog extends Animal {
  void sound() {
    System.out.println("Bark");
  }
}

Polymorphism

Polymorphism allows methods to behave differently based on objects.

Exception Handling

Exceptions handle runtime errors using try-catch.

try {
  int x = 10 / 0;
} catch (Exception e) {
  System.out.println("Error occurred");
}

Collections

The Collections Framework manages groups of objects.

ArrayList list = new ArrayList<>();
list.add("Java");

File I/O

Java reads and writes files using streams.

File file = new File("data.txt");

Multithreading

Threads allow concurrent execution.

class MyThread extends Thread {
  public void run() {
    System.out.println("Running");
  }
}

JDBC

JDBC connects Java applications to databases.

Java GUI

Java provides Swing and JavaFX for graphical user interfaces.

Best Practices

Write clean code, use meaningful names, and follow Java conventions.
